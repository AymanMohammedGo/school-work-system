# منظومة العمل المدرسي — شاشة عرض تفاعلية

واجهة عرض تفاعلية لوزارة التعليم — المملكة العربية السعودية.
مصمَّمة كـ **خريطة منظومة تعليمية** (Interactive Ecosystem)، وليست لوحة بطاقات أو Dashboard.

## الرابط المباشر

**<https://aymanmohammedgo.github.io/school-work-system/>**

يُحدَّث تلقائيًا عند كل `git push` إلى الفرع `main` (خلال دقيقة تقريبًا).

> المستودع **عام (Public)** لأن GitHub Pages المجاني يشترط ذلك.

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح. لا يوجد build ولا تبعيات.

## بنية المشروع

```
school-interactive-display/
├── index.html          ← البنية فقط
├── css/style.css       ← نظام التصميم كاملًا

├── assets/logo/

```

## إضافة روابط Google Drive

كل المحتوى في مكان واحد: مصفوفة `SECTIONS` في أعلى `js/app.js`.
أضف الرابط في حقل `url` — لا شيء آخر يحتاج تعديلًا:

```javascript
{ id: 1, title: 'التقويم المدرسي الخارجي', icon: 'calendar', slot: 'top', url: 'https://drive.google.com/...' },
```

| الحقل   | المعنى |
|---------|--------|
| `id`    | الرقم المعروض (01–13) |
| `title` | العنوان — **لا يُعدَّل** |
| `icon`  | مفتاح من نظام الأيقونات في `ICONS` |
| `slot`  | الموضع في التركيب: `top` (٥) · `start` (٢ يمين) · `end` (٢ يسار) · `bottom` (٤) |
| `url`   | رابط Google Drive |

- `url` فارغ ⇒ يُبنى العنصر كـ `<button>` غير مفعَّل.
- `url` موجود ⇒ يُبنى كـ `<a target="_blank" rel="noopener noreferrer">`.

## التصميم

**الفكرة:** نواة هوية مركزية تتصل بـ13 عنصرًا موزّعة في حلقة غير متماثلة
(قوس علوي ٥ · جناحان ٢+٢ · قوس سفلي ٤)، مع خطوط ربط رفيعة تُحسب من
الهندسة الحقيقية للعناصر في DOM.

- **التخطيط** — CSS Grid. المواضع بنيوية وليست نِسبًا مكتوبة يدويًا،
  لذلك التداخل مستحيل هندسيًا لا بالضبط اليدوي.
- **الخط** — IBM Plex Sans Arabic. أُزيل `letter-spacing` الموجب من كل نص عربي
  لأنه يكسر اتصال الحروف.
- **الشكل** — زاوية قائمة واحدة في الجهة الأمامية (أعلى اليمين) لكل لوحة
  وللنواة: عنصر معماري موحّد بدل الحواف الدائرية المتشابهة.
- **اللون** — أخضر مؤسسي عميق + زمردي للتفاعل. الذهبي/الرملي ثانوي تمامًا
  (معيّن النواة فقط).
- **الحركة** — دخول متدرّج يبدأ من المركز ثم يمسح للخارج، ثم سكون تام.
  لا حركة مستمرة. `prefers-reduced-motion` مدعوم.

## السلوك حسب المقاس

| العرض / النسبة | التخطيط |
|---|---|
| ≥ 1100px أفقي | الحلقة الكاملة — ضبط مستقل لـ 3:2 و 16:9 |
| 900–1100px أفقي | الحلقة نفسها بكثافة أعلى |
| < 900px **أو** نسبة < 1.1 (رأسي) | قائمة مكدّسة بعمودين + تمرير رأسي |
| < 430px | عمود واحد |

في الوضع المكدّس تُخفى خطوط الربط (لأنها تصف حلقة لم تعد موجودة)،
وتتصدّر النواة القائمة، ويُسمح بالتمرير — قاعدة «بدون تمرير» تخصّ شاشة العرض الجدارية فقط.

## المقاسات المستهدفة

| الجهاز | النسبة | الحالة |
|--------|--------|--------|
| شاشة عرض 3م × 2م | **3:2 (أساسي)** | مُختبَرة |
| 1920×1080 / 2560×1440 / 3840×2160 | 16:9 | مُختبَرة — تركيب مُعاد ضبطه، ليس تصغيرًا |
| ≥ 1.62 | عريض | يتمدد أفقيًا ويقلّ ارتفاعه |
| ≤ 1.34 | أقرب للمربع | تُسحب الأجنحة للداخل |

## التفاعل

- **لمس** أولًا (`pointer` events + `touch-action: manipulation`)
- **فأرة** ثانيًا
- **لوحة مفاتيح**: `Tab` للتنقل، `Enter`/`Space` للفتح،
  والأسهم للتنقل المكاني بين العناصر حسب موضعها على الشاشة
- تركيز ظاهر بوضوح (`:focus-visible`)

## ملاحظة تشغيلية

الخطوط تُحمَّل من Google Fonts. إذا كانت شاشة العرض **بدون إنترنت**،
نزِّل عائلة IBM Plex Sans Arabic محليًا وبدّل رابط `<link>` في `index.html`
بملف `@font-face` محلي. يوجد fallback إلى Tajawal ثم خط النظام.
